# Program overview

AICA is an independent engineering initiative in early-stage development. It is not presenting a finished aircraft, validated propulsion system, completed prototype, or production-ready design.

## Current phase

The current phase is **documentation baseline**. Public work defines scope, terminology, technical questions, assumptions, measurement expectations, risks, and decision standards for possible future model work.

## Program boundary

The engineering program covers documentation, model definition, controlled evaluation, and evidence-based decisions about whether later prototype work is justified. It contains no token program or investment proposition.

## Decision standard

Each phase should reduce uncertainty before another layer of complexity is introduced. Work may be revised, delayed, suspended, or discontinued if evidence, safety constraints, resources, or feasibility do not support continuation.

## Evidence status

No public technical validation result is currently available. Readers should evaluate only the evidence actually published and should not treat undisclosed concept details as proof of novelty, feasibility, intellectual-property protection, or performance.
