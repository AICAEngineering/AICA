# About AICA

AICA is an **independent engineering initiative** in early-stage development. Its purpose is to move a vertical-mobility concept from private assumptions into a documentation-first process that can support responsible technical review and, if justified, future physical evaluation.

AICA is not presenting a validated aircraft, completed propulsion system, certified design, or production program. No public prototype or test result is claimed.

## Mission

Define a measured path from concept toward prototype validation. The current work is a documentation baseline: clarifying technical questions, development boundaries, model requirements, measurement expectations, and decision standards before added complexity is considered.

## Engineering philosophy

- Claims should follow repeatable evidence.
- Simple, inspectable models should precede integrated systems.
- Assumptions and acceptance criteria should be recorded before testing.
- Safety constraints, failure modes, and unresolved questions should remain visible.
- Inconclusive and unsuccessful results should remain part of the development record.

## Public boundary

Public material distinguishes current status, intended process, and future conditional work. Concept-specific information may remain undisclosed for safety or intellectual-property reasons; that limitation is not evidence of novelty, feasibility, protection, or validation.

The AICA engineering program contains no token offering or investment proposition. Any future token initiative, if considered, would be separate and would require its own documentation and review.
