# Engineering roadmap

This roadmap is conditional. Later phases proceed only if earlier work provides enough evidence to justify added complexity and risk. It contains no promise of completion dates, technical success, certification, production, or deployment.

## Phase 1 — Documentation baseline

**Status: Current**

Define the concept boundary, intended use questions, assumptions, known unknowns, research standards, and decision criteria. The output is a reviewable baseline, not technical validation.

## Phase 2 — Model definition

**Status: Planned**

Specify a limited model or subsystem, expected behavior, instrumentation, operating limits, hazards, and acceptance criteria before construction or evaluation is considered.

## Phase 3 — Controlled bench evaluation

**Status: Conditional**

If authorized and feasible, evaluate isolated behavior under controlled conditions and record configuration, inputs, conditions, measurements, anomalies, and safety observations.

## Phase 4 — Integrated prototype decision

**Status: Conditional**

Review the available evidence and decide whether an integrated prototype is justified. The program may revise, pause, or stop instead.

## Phase 5 — Prototype validation

**Status: Future and conditional**

Only if earlier phases support it, define repeatable prototype validation work. A demonstration alone would not establish safety, reliability, scalability, certification readiness, or commercial viability.
